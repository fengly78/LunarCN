# 月光 · 中文显示器控制

基于 Lunar 的公开设计和 MIT 许可的 [m1ddc](https://github.com/waydabber/m1ddc) 后端开发的独立 macOS 应用，不依赖 Lunar Pro 源码或旧版 Intel 框架。

## 当前功能（0.6.1）

- 简体中文原生界面、菜单栏入口、单实例运行和可调整大小的窗口。
- 按 UUID 保存每屏亮度范围及一份设备预设；恢复预设由按钮触发。
- 每台外接屏可开启“自动亮度 · 跟随内建屏”，按系统亮度百分比跟随并遵守每屏亮度范围。
- DDC 写入未确认后暂停对应调节，保留刷新及手动允许重试入口。
- 显示器识别，连接变化及睡眠唤醒后刷新。
- 内置屏幕的系统亮度控制，使用 DisplayServices 读写并检查返回状态。
- 支持 DDC/CI 的外接屏亮度、对比度控制。
- 设备支持时提供外接显示器硬件音量、静音控制，按返回能力显示操作项。
- 读取显示器实际范围并换算百分比；内建屏与外接屏亮度拖动即调节，无需点击应用。
- 高频亮度目标按每屏合并，保留最新值；外接屏按硬件响应串行写入并读回确认。对比度、音量和静音仍点击“应用其他更改”后写入。
- 每次控制核对显示器 ID 和 UUID，写入后读回确认；失败和超时显示中文提示。
- 独立关闭和恢复笔记本内置屏幕；关闭后内置屏从活动、在线显示器列表中移除，键盘和触控板仍可使用。
- 关闭前检查实体外接屏并把控制窗口移到外接屏，15 秒内未确认则恢复。
- 独立保护进程监视外接屏和主应用连接，断开外接屏、退出或主应用异常结束时尝试恢复内置屏。

尚未实现独立环境光／时间调光、HDR/XDR、外接屏关闭、输入源切换和全局快捷键。界面未提供软件遮罩调光；不支持的显示器会显示原因。完整差异和验收要求见[原版功能对照清单](../docs/lunar-feature-parity.zh-CN.md)。

## 拖动亮度立即调节

内建屏和外接屏的亮度滑块移动后直接调节，键盘／辅助功能对滑块的修改也使用同一通道，无需应用按钮。拖动期间不会锁住滑块；较早读回的值不覆盖较新的目标。每屏只保留一个最新待写目标，共用串行控制队列；内建屏两次操作至少间隔约 50 毫秒，外接屏约 150 毫秒，实际响应还受设备耗时影响。

调节前核对显示器身份、当前硬件范围和用户范围，写入后使用设备读回值更新显示。读取或写入失败时暂停此屏实时亮度并丢弃其待写目标；检查连接后可“允许重试写入”。刷新、睡眠、关闭内建屏或退出会取消后续待写操作，已发送的一次写入可能完成。

自动跟随开启时手动亮度滑块禁用，关闭跟随后即可拖动。对比度、音量和静音继续暂存，再点击“应用其他更改”；预设保存按钮在亮度调节完成后可用，保存的是设备确认值。

## 自动亮度：外接屏跟随内建屏

1. 在 macOS“系统设置 → 显示器”中按需开启内建屏的自动亮度。月光不会修改该系统开关。
2. 内建屏保持开启，在目标外接屏卡片开启“自动亮度 · 跟随内建屏”。每台外接屏独立保存开关，默认关闭。
3. 应用约每 2 秒读取内建屏和外接屏，仅调整外接屏亮度；通常每次目标最多移动 5 个百分点，忽略小于 1.5 个百分点的变化以减少抖动。硬件最小步进可能影响实际精度；若当前值超出用户范围，会先限制到范围内。
4. 内建屏关闭／休眠或不可读时暂停跟随，外接屏保持当前亮度；内建屏恢复且应用运行时继续。写入或外接屏读取失败则暂停对应项目，检查连接后点击“允许重试写入”。
5. 关闭自动亮度后可手动移动亮度滑块；恢复一个不同亮度的预设也会关闭此屏跟随。音量、对比度仍可单独手动控制。

开关按 UUID 保存，重启应用后已开启的屏幕会恢复跟随。关闭开关、刷新连接、休眠或退出会取消后续自动任务；已经发送给设备的一次写入可能完成。停止自动亮度后保留设备最后亮度，不自动跳回开启前的值。连接变化导致 UUID 改变时按新设备处理，默认关闭跟随。

本模式跟随百分比，不能保证不同面板的实际亮度（nits）相同；不直接读取环境光，不替代 macOS 内建屏的自动亮度。内建屏关闭时不会凭旧读数继续自动调节。

## 关闭笔记本屏幕

1. 连接并开启实体外接显示器，打开月光。
2. 点击顶部“笔记本屏幕”卡片中的“关闭内置屏幕”。应用窗口会移到外接屏。
3. 确认外接屏画面可见后，在 15 秒内点击“保持关闭”；否则内置屏自动恢复。
4. 点击“恢复内置屏幕”可重新开启。退出月光也会通知保护进程恢复。

此操作不降低屏幕亮度，也不要求合上笔记本盖子。状态只应用于当前登录会话，没有写入永久显示配置。系统睡眠、开合盖或热插拔可能自行恢复屏幕，本版本不会强制再次关闭。

需要命令行恢复时，可在仓库根目录运行：

```sh
build/lunar-cn/LunarCN.app/Contents/MacOS/LunarCN --restore-display
```

## 构建和运行

需要 Apple Silicon Mac、macOS 13 或更高版本以及 Xcode 命令行工具。使用系统 Swift 和 Clang，无需下载 SwiftPM 或 Carthage 依赖。

在仓库根目录执行：

```sh
bash LunarCN/build.sh
open build/lunar-cn/LunarCN.app
```

产物位于 `build/lunar-cn/LunarCN.app`，压缩包为同目录下的 `LunarCN.zip`。应用使用独立标识 `local.lunarcn.displaycontrol`，不会复用官方 Lunar 的设置。

构建脚本使用本机临时签名，不执行安装、遥测上传或官方自动更新。临时签名不等同于 Developer ID 签名或 Apple 公证；在其他电脑上分发需另行处理签名和公证。

## 本机发行包

```sh
bash LunarCN/release.sh
```

生成 `build/lunar-cn/releases/0.6.1/` 下的 DMG、应用 ZIP、源码 ZIP、`SHA256SUMS` 和 `release.json`。脚本只读挂载 DMG，核对版本、签名并运行自检；不会上传或安装到系统目录。DMG 中将应用拖到 Applications 即可安装，ZIP 解压后移动到应用程序文件夹。详见 [安装说明](Install.zh-CN.txt) 和 [版本说明](RELEASE-NOTES.zh-CN.md)。

“设置与预设”保存最近读回的设备值，未应用的对比度／音量／静音数值不会存入预设；每屏一份，保存会替换。范围只约束月光发出的亮度目标，不会覆盖其他程序或系统的调节。超出范围的已保存预设会提示调整，恢复时不会自动放宽限制。连接变化导致 UUID 改变时按新设备处理。

## 自检

构建脚本自动运行不操作真实显示器的自检，也可手动运行：

```sh
build/lunar-cn/LunarCN.app/Contents/MacOS/LunarCN --self-test
```

自检覆盖实时亮度目标合并、最终值与返回原值、取消与失败、自动跟随分步与防抖、停用／取消／休眠源保护、旧设置兼容、设置持久化和隔离、损坏数据保护、预设及范围校验、屏幕恢复决策、静音枚举、辅助进程失败／未确认／超时及 DDC 数据包解析。真实显示器控制需要在目标屏幕、连接线和扩展坞组合上验证，构建或自检通过不代表所有硬件兼容。

本次已在 Apple Silicon、macOS 27.2.1、Xcode 27.2 上完成 ARM64 构建、自检及本机临时签名校验。实际界面识别了 DELL U3225QE 和内置视网膜屏幕，成功读取外接屏亮度、对比度及内置屏亮度，并检查了滑块预览和刷新。

内置屏实际关闭后，系统查询返回 `active=0, online=0`，外接屏仍然活动。已实测未确认后的自动恢复、确认保持关闭超过 15 秒、按钮恢复、命令行恢复，以及主应用进程被 `SIGKILL` 后由保护进程恢复；恢复后内置屏 `active=1, online=1`。尚未进行真实拔线、合盖或睡眠唤醒测试，其他硬件组合也未验收。当前 Dell 连接外接屏亮度 65 → 64 → 65 已通过写入确认和原值恢复，对比度写入仍待验收。

0.2.1 修复了内置屏错误使用 CoreDisplay 读写亮度的问题：本机 CoreDisplay 返回固定 `1.0`，DisplayServices 返回实际值 `0.0625`。已通过应用界面设置为 `9%`，独立系统读取为 `0.0900000036`，应用显示“已应用并读取确认”；测试后精确恢复原始值 `0.0625` 并刷新界面。没有修改系统自动亮度设置。

0.3.0 接入了 DDC 音量和静音。当前 DELL U3225QE 音量可读，但请求 51%／55% 后仍读回 50%，写入尚未通过；静音未返回有效枚举，界面不展示对应开关。协议及状态解析自检通过不代表该硬件已经支持写入，详见功能对照清单。

如果官方 Lunar 或其他自动调光程序同时运行，它们可能覆盖手动设置。使用本应用进行手动调节前，可先暂停其他程序的自动调光。

显示器自身的自动亮度也会覆盖手动值和“跟随内建屏”的目标。DELL U3225QE 对照验证中，开启自身自动亮度时读数回落至 3%，关闭后恢复循环保持目标值。使用月光手动亮度或跟随内建屏前，请在显示器菜单关闭自身自动亮度。月光不自动更改传感器开关，写入未确认时保留暂停和重试保护。

## 来源及维护

`Vendor/m1ddc` 固定于 `7339ceebb03f691b1eaeb8471dca301d215d19c8`。本地补丁、上游链接和许可说明见 [NOTICE.txt](NOTICE.txt) 及 [m1ddc 的 MIT 许可](Vendor/m1ddc/LICENSE)。本仓库仅发布独立中文应用；原始工程见 [alin23/Lunar](https://github.com/alin23/Lunar)。

DDC、内置屏亮度及内置屏启停均使用系统未公开承诺稳定的接口，macOS 更新后可能需要适配。屏幕启停接口研究参考 [Lunar 作者的公开文章](https://alinpanaitiu.com/blog/turn-off-macbook-display-clamshell/)。自动跟随默认关闭；未启用时启动与刷新只读取设置，已保存的跟随开关开启时会恢复自动调节。亮度拖动即写入，其他手动关闭、恢复或应用操作由按钮触发。恢复命令及关闭后的保护进程也会按上述规则恢复内置屏幕。

系统能报告外接设备已连接，但无法保证外接显示器面板真的可见，例如接入 EDID 模拟器或某些扩展坞时。首次关闭后的限时确认用于降低此类风险；保护机制不等于所有硬件异常下都能保证恢复。
