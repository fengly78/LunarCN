# 月光 0.6.1

修复显示器休眠被误判为内建屏断开、重复恢复并发、迟到消息覆盖恢复状态及中文管道消息乱码。主动恢复先唤醒显示器，保护进程按实体外接屏的在线状态判断连接。

DDC 响应等待提高到 50 毫秒，最多五次读取并采用有限退避，查询与写后确认共用四秒预算。未就绪和无效报文继续视为失败；写入未确认时继续暂停对应调节。

本机通过显示器休眠／唤醒回归、12 次关闭／恢复循环和 60 次 DDC 命令确认。使用手动亮度或跟随内建屏时，需关闭显示器自身自动亮度，避免覆盖目标。完整结果、对照和限制见 [0.6.1 验证记录](https://github.com/fengly78/LunarCN/blob/v0.6.1/docs/stability-0.6.1.zh-CN.md)，安装盘也附有“验证记录.md”。

仍为本机临时签名的试用版，未经 Apple 公证；真实拔线、合盖、整机睡眠及其他硬件尚未验收。

# 月光 0.6.0

内建屏与外接屏亮度支持拖动即调节，不再需要点击应用；自动亮度与每屏范围继续生效。对比度、音量、静音保持暂存，按钮更名为“应用其他更改”。

- 滑块调节期间保持可拖动，按每屏保留一个最新待写目标，共用串行队列，避免大量旧目标堆积。
- 内建屏操作间隔至少约 50 毫秒，外接屏约 150 毫秒，加上设备实际响应时间；松手后的最终值仍会完成。
- 调节前重新读取硬件范围；成功后直接使用已确认读回值，界面显示最新目标与最终设备值。
- 读取或写入失败时暂停对应屏的实时调节，丢弃其剩余目标，允许手动重试；刷新、睡眠、关闭内建屏与退出取消后续请求。
- 自动跟随开启时亮度滑块禁用；手动调节内建屏期间暂停自动任务，停止拖动后继续正常跟随。
- 调节期间不保存旧的设备值，预设按钮在调节完成后重新可用。

自检覆盖一万次输入只保留一个最新目标、多个 UUID 隔离及轮转、回拖至原值、无变化时跳过写入、写前取消、断连和未确认失败。原有自动亮度及恢复策略自检保留。

修改文件：`Sources/LiveBrightness.swift`、`Sources/App.swift`、`Sources/DisplayControl.swift`、`Sources/AutomaticBrightness.swift`、`Sources/SelfTests.swift`、`build.sh`、`Info.plist`、`README.zh-CN.md`、`Install.zh-CN.txt`、`NOTICE.txt`、本说明与 `docs/lunar-feature-parity.zh-CN.md`。

本机 0.6.0 验证：Dell 通过滑块从 3% 调到 8%，实际拖动至 12% 再拖回 3%，全程未点击应用按钮，界面和设备确认值一致；暂存的对比度 49% 没有随亮度写入，独立读取仍为 50%。内建屏滑块直接设置为 43%，独立系统读取为 `0.4300000071525574`，随后精确恢复原始 `0.41598325967788696`。最终外接屏为 3%，内建屏已恢复测试前的关闭状态，自动跟随保持关闭。

本机临时签名，未经 Apple 公证。真实多屏同时拖动、睡眠唤醒及其他硬件仍未验收。以下保留前版记录。

# 月光 0.5.0

增加外接屏自动亮度：每台外接屏独立开启“自动亮度 · 跟随内建屏”，配合 macOS 的系统自动亮度。此模式跟随百分比，不是独立环境光传感器模式，也不保证不同屏幕亮度的 nits 一致。

- 约每 2 秒检查，分步调整并减少小幅波动，遵守每屏亮度上下限；超出限制时先限制到范围内，实际精度受硬件步进影响。
- 无效 DDC 读取最多尝试三次，重试之间等待 100 毫秒；不重复发送设置命令。
- 开始关闭内建屏前先取消自动任务，避免跟随切换期间的读数；关闭／休眠／不可读时暂停，恢复后继续；外接屏读取或写入失败时暂停对应项目，手动允许重试。
- 默认关闭，按 UUID 保存；兼容 0.4.0 的范围与预设。用户曾开启的跟随会在重启应用后恢复。
- 跟随时亮度滑块禁用；关闭开关即可手动调节。恢复不同亮度的预设会关闭此屏跟随，不影响音量与对比度操作。
- 关闭、刷新、睡眠或退出取消后续自动任务；已发送给设备的一次写入可能完成，停止时保留设备最后亮度。

修改文件：`Sources/DDCHelper.m`、`Sources/AutomaticBrightness.swift`、`Sources/DisplayControl.swift`、`Sources/Preferences.swift`、`Sources/BuiltinDisplay.swift`、`Sources/App.swift`、`Sources/SelfTests.swift`、`build.sh`、`Info.plist`、`NOTICE.txt`、`README.zh-CN.md`、`Install.zh-CN.txt`、本说明及 `docs/lunar-feature-parity.zh-CN.md`。

自检覆盖分步、方向、防抖、范围、非法来源、停用和取消、源屏在写入前关闭、只读目标跳过、写入失败，以及旧版设置兼容与开关隔离。DMG／ZIP 继续使用本机临时签名，未做 Apple 公证。

本机 0.5.0 验证：DELL U3225QE 从 3% 分步跟随到 42%（内建屏读数约 41.6%），自动更新期间未应用的对比度 49% 草稿保留；重启后跟随开关仍开启。无效读取重试修正后，连续 30 次 DDC 亮度读取全部通过。实际关闭内建屏并保持后，独立系统查询为 `active=0, online=0`，外接屏连续三次读回均为 13%，界面显示暂停跟随。测试后关闭自动跟随，经界面把外接屏亮度恢复为原始 3%，内建屏保持原先的关闭状态。

真实睡眠／唤醒、多台外接屏和其他硬件仍未验收；相关取消、跳过和故障策略已有模拟自检。未直接测试环境光变化，跟随的是内建屏亮度百分比，不会修改系统自动亮度开关。

以下保留 0.4.0 的既有能力与验证记录。

# 月光 0.4.0

本机试用版，面向 Apple Silicon、macOS 13 或更高版本。构建环境为 macOS 27.2.1、Xcode 27.2。本版独立实现中文显示器控制，不等同于原版 Lunar 的全部能力。

## 本版完善

- 每屏亮度上限、下限及单个设备预设，按系统 UUID 持久保存；启动只读取，恢复预设由按钮触发。
- 设置损坏时保留原记录并提示，避免静默覆盖。
- DDC 写入后未读回目标值时，暂停该项目的后续写入；检查连接后可手动允许重试，刷新仍可用。
- 单实例运行、重复打开时唤起窗口；窗口可调整大小，增加应用图标。
- 本地 DMG、应用 ZIP、源码 ZIP 和 SHA-256 校验文件；DMG 自动只读挂载并运行自检。

## 既有功能和验收

内置屏系统亮度，外接屏 DDC 亮度、对比度及设备提供的音量／静音；关闭笔记本内置屏幕，15 秒确认及独立恢复进程。

本机已实测内置屏亮度调整并精确恢复；内置屏关闭后 `active=0, online=0`，外接屏保持活动。未确认倒计时恢复、保持关闭超过 15 秒、按钮恢复、CLI 恢复，以及主进程被 SIGKILL 后独立恢复均已通过。屏幕保护引擎在本版未改动。

当前 DELL U3225QE 连接已测试硬件亮度 `65 → 64 → 65` 并恢复原值；每次按 ID 和 UUID 核对。此前调整连接／输入源时系统 UUID 曾变化，旧标识已停止写入。音量在此前连接中可读但写入未获确认，静音未返回有效枚举；不能把可读判定为可写。

自动自检覆盖设置持久化和隔离、损坏记录保护、范围和预设校验、恢复决策、静音枚举、辅助进程失败／超时／未确认状态和 DDC 数据包。真实拔线、合盖、睡眠唤醒及其他硬件组合尚未验收。

0.4.0 实际界面检查通过：修改亮度下限、保存范围、保存预设、退出重启后保留；暂存音量为 49% 时保存的预设仍为最近读回的 50%。相同预设提示无需重复应用。测试后已恢复默认 0%–100% 范围，没有写入测试滑块数值；重复启动后只有一个 GUI 进程。

## 范围与限制

尚未实现自动调光、HDR/XDR、软件调光、外接屏关闭、输入源切换和全局快捷键；完整差异见源码包内 `docs/lunar-feature-parity.zh-CN.md`。

显示器 UUID 可能随端口或输入源变化，设置不会自动迁移。每屏只保存一份预设，保存会替换上一份；恢复时跳过不可用或暂停的项目，超出当前亮度限制则提示，不自动放宽限制。多屏场景和快捷键预设留待后续实现。

DDC 和内置屏接口未获系统公开稳定性保证，macOS 更新可能需要适配。临时签名并非 Developer ID 签名，未做 Apple 公证；发行包仅完成本机验证。
